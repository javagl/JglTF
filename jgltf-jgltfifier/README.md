# jgltf-jgltfifier

A library that takes a glTF model and generates the JglTF code that generates
the glTF model. 

> Think about this sentence for a while, or just try it ...

(This quote and the name of the library are a tribute to 
[Apache BCELifier](https://commons.apache.org/proper/commons-bcel/manual/appendix.html#BCELifier))

**Note:** This library is still subject to change.
